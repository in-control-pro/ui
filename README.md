# @in-control/ui

Una biblioteca de componentes UI basada en shadcn/ui.

## Instalación

```bash
npm install @in-control/ui
# o
yarn add @in-control/ui
# o
pnpm add @in-control/ui
```

## Uso

```jsx
import { Button } from '@in-control/ui';

function App() {
  return <Button>Click me</Button>;
}
```

## Documentación

Para ver todos los componentes disponibles y sus ejemplos, ejecuta:

```bash
npm run storybook
```
